1. Sequence Tokenization Preprocessing

Input text sentences are split into individual tokens and mapped to integer indices based on the vocabulary index dictionary.

"I am learning Python"
➔ [12, 4, 89, 45]
➔ Sequences: [[12, 4], [12, 4, 89], [12, 4, 89, 45]]
2. Word Embedding Matrix Representation

Each discrete word index is converted into a 128-dimensional continuous vector space representation that captures semantic relations.

Embedding Dimension: 128
Input Shape: (Batch_Size, Sequence_Length)
Output Shape: (Batch_Size, Sequence_Length, 128)
3. LSTM Recurrent Cell Recurrence

Long Short-Term Memory cells use forget gates, input gates, and cell states to store long-term sequence dependencies without vanishing gradients.

f_t = σ(W_f · [h_{t-1}, x_t] + b_f)
i_t = σ(W_i · [h_{t-1}, x_t] + b_i)
C_t = f_t * C_{t-1} + i_t * C~_t
4. Softmax Output Layer Probability

The final dense layer applies the Softmax activation function over the entire vocabulary dimension, converting logits into normalized probabilities summing to 1.

P(y = w_i | x) = exp(z_i) / Σ exp(z_j)
Output Vector Dimension: Vocab_Size (N)
